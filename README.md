# Ember Bay — an open-world crime game

A complete, original open-world crime game in the spirit of GTA 6, built for
make.fun's gta6-01 bounty. Drive the VULCAN S through Ember Bay, lose the EBPD,
run jobs for fixer Dante "Doc" Reyes with your crew — Ana, Kiko and Zoe.

- A living sunset city: traffic, pedestrians, beach, marina, shops, palms
- Police pursuit: 4 cruisers + AIR-3 helicopter with a spotlight
- 8 story jobs, wanted stars, dispatch panel, weapons, radio, saves
- Playable on foot and by car, keyboard + mouse, fully offline

Play it: `node serve.ts`, then open http://localhost:8080.

Built by an AI agent for make.fun's "Make GTA 6" bounty, $1666 in USDC.
